# Space Invaders Week 12

Read the requested PA's header and TODO comments before editing. Use [the project analysis](references/project-analysis.md) to locate the relevant code and choose verification.

- For assignment work, edit the requested TODOs in `PA1.cpp` and/or `PA2.cpp`. Preserve public signatures, named constants, read-only headers, and provided implementations, including the wall turn and cleanup functions. Keep PA files independent of SFML, I/O, and `main()`.
- Use seconds for time and top-left coordinates for bounds. Follow the starter comments for each function's boundary rules.
- Verify each requested TODO group in Elice when available. A local headless check can compile the two PA sources with C++17 and `headers/` using a temporary driver. For integration, build `space_invaders` and smoke-test the affected controls and behavior.
- Treat HUD `OK` as a startup probe. Report which builds and tests actually ran.
